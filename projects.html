kaResearch · Georgian speech recognition

In progress

How well does Georgian speech recognition survive a phone line?

An open benchmark of Georgian ASR models, open and commercial, on clean audio versus real telephone audio, because phone calls are much harder than the clean recordings models are usually tested on.

  • The same recordings tested clean at 16 kHz, through a simulated phone line (8 kHz, G.711 μ-law) and on real consented calls.
  • One harness: dataset loaders, a model registry, Georgian text normalisation and error metrics, so every model is scored the same way.
  • Planned: a write-up of the results, then fine-tuning a NeMo FastConformer model for Georgian telephone speech.

VertAPI · my own product, 2026

Georgia's public registries, one request away

VertAPI watches Georgian public registries every morning and tells businesses when a record they care about changes, through an API, an email with an Excel file, or Telegram.

  • Building permits: new large projects in Tbilisi and Batumi, with the developer named, before construction starts. Live with pilot customers.
  • Property and collateral watch for lenders: new mortgages, seizures and owner changes by cadastral code. Supplier VAT status and company data are next.
  • I cleared automated access with each registry before building on it; the collectors keep to polite rate limits and never go behind a captcha.
  • One API key per customer, daily quotas, and error messages in English and Georgian. MCP access for AI agents is coming.
